Run an argument vector to explore the checkout or verify behavior. Installed git, rg, grep, cat, sed, awk, head, tail, find, and available test/build tools can inspect source, callers, dependencies, tests, and documentation directly; read_file and read_diff are optional alternatives. For example, use {"argv":["rg","-n","functionName","src"]} or {"argv":["git","show","<recorded-head-sha>:src/file.ts"]}. No shell is used automatically: pipes and redirections in argv are literal arguments.

cwd defaults to the review checkout and must remain inside it, including through symlinks. Relative PATH entries are ignored. Direct Git commands disable hooks, external protocols, system/user configuration and interactive credentials. Use only commands needed for the review; do not publish comments or change repository history. Arbitrary programs run within the existing isolated job, with its read-only checkout, installed tools, resource limits, sanitized command environment and network policy. cwd validation alone is not a filesystem sandbox.

timeoutMs and maxOutputBytes can lower trusted limits. Results include exitCode, stdout, stderr, timedOut, cancelled, truncated and durationMs. Complete process groups are terminated on command exit, deadline or cancellation. A nonzero exit, truncated output, timeout or unavailable dependency is a limitation; never report an unobserved check as passed. Final finding locations must refer to the recorded immutable head revision, even when commands discover the source.
