Run an argument vector to inspect repository state or verify a finding with focused tests, compilers, linters, static analyzers or Git commands. No shell is used automatically. cwd defaults to the review checkout and must remain inside it, including through symlinks. timeoutMs and maxOutputBytes can lower trusted execution limits. Results include exitCode, stdout, stderr, timedOut, cancelled, truncated and durationMs. A nonzero exit, timeout or unavailable dependency is a verification limitation, not proof of a defect. Use only commands needed for the review; do not publish comments or change repository history. Writable files, installed tools and network access depend on the isolated job's policy.
