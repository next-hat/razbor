Read a repository-relative UTF-8 Git blob at revision head (default) or baseline. Optional startLine/endLine are inclusive, one-based. Returns line-numbered source, selected SHA and range, nextStartLine and explicit absent/unsupported/unavailable states. At most 400 lines and 100000 bytes; oversized blobs are unavailable. Related unchanged files are allowed. Symlinks/submodules are never followed. Use baselinePath for old renamed/deleted files and headPath for new source. Use exec or optional cbm_* tools for discovering related symbols and callers; this tool can verify targeted ranges at the PR revision. The shared index describes its own branch commit, not head or baseline.
